모각작 데이터 수집 관리 엑셀
============================

★ 이 파일의 목적
  서비스에서 일어나는 **모든 이벤트**를 목록화하고,
  각각을 **수집 가능하게** 만들기 위한 관리 대장.

  - 엑셀 = 전체 이벤트/지표 카탈로그 (빠짐없이)
  - 대시보드 = 그중 유의미한 것·같이 봐야 하는 것 시각화


★ 메인 파일
  모각작_데이터수집_관리.csv  (Excel에서 바로 열기: UTF-8 BOM)

★ Google Sheet(gid=133562216) 미러
  모각작_데이터수집_시트_이벤트목록.csv
  _sheet_gid133562216_신규5행.csv  ← 시트에 붙여넣을 신규 행만


핵심 컬럼
---------
수집목표
  - 수집필수 : 서비스 이벤트 → 원칙적으로 전부 수집 가능해야 함
  - 선택     : 운영/시스템/분석가치 낮은 것

수집가능상태  ← 지금 당장 모을 수 있는지
  - 즉시수집가능(파이프라인중)           : 이미 run.bat으로 가져옴
  - 즉시수집가능(DB있음·파이프라인확장) : DB에 있어 파이프라인만 추가하면 됨
  - 부분수집(GA만)                     : GA에만 있음 → 파이프라인/DB 보강 필요
  - 부분수집(상태만·이력없음)           : 현재값만 있고 “언제 했는지” 이력 없음
  - 미수집(로그없음·BE/FE보강필요)       : 코드에 로그가 없음 → 개발 필요
  - 시스템조회(분석가치낮음)

대시보드후보 : 핵심 / 후보 / 참고 / 제외


유저·그룹방 상세 (자주 묻는 것)
------------------------------
  UG_USER_GROUP_LIST     유저가 어떤 그룹방들 가지는지     → 이미 스냅샷 수집중
  UG_GROUP_COUNT_PER_USER 그룹방 몇 개                     → 스냅샷으로 바로 집계 가능
  UG_LAST_ENTERED        최근(마지막) 입장 시각            → 있음(덮어쓰기 1개)
  UG_ENTER_HISTORY       입장할 때마다 쌓이는 이력         → 아직 없음(BE 보강 필요)
  UG_SESSION_LEAVE       퇴장 이력                         → 아직 없음


필터 추천
---------
  1) 수집가능상태 = 미수집…          → 개발에 “로그 추가” 요청할 목록
  2) 수집가능상태 = 즉시…파이프라인확장 → 파이프라인만 늘리면 되는 목록
  3) 대시보드후보 = 핵심             → 대시보드에 먼저 넣을 것
  4) 대분류 = 그룹·멤버십            → 유저-그룹 상세


주의
----
  “수집 가능해야 한다” = 엑셀에 다 적혀 있어야 하고,
  상태가 미수집이면 **앞으로 BE/FE/파이프라인으로 채울 백로그**입니다.
  지금 파이프라인이 이미 다 가져오고 있다는 뜻은 아닙니다.
