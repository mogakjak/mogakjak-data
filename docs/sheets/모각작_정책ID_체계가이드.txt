모각작 정책 ID 체계 (단순 버전)
================================

## 형식
- `도메인2글자` + `번호2자리` (예: AU01, GH03, MC06)
- 같은 정책 = 같은 ID (홈·마이페이지·할일 등 중복 참조 행도 동일 ID)
- 레이아웃 전용(그리드·스크롤 높이·FAB 등)은 ID 미부여

## 도메인 접두어
| 접두어 | 영역 | 예시 |
|--------|------|------|
| AU | 가입·약관·로그인·탈퇴 | AU01 가입, AU05 로그인 필요 |
| ST | 상태·용어 | ST02 몰입, ST03 휴식 |
| SH | 사이드바(홈) | SH01 명언 |
| SG | 사이드바(그룹방) | SG01 작업 공개 |
| SD | 사이드바(공통) | SD02 작업 선택, SD04 누적시간 |
| TM | 개인 타이머 | TM01 시작, TM02 누적 반영 |
| HM | 홈 전용 | HM01 그룹목록 API |
| LN | 공식 라운지 | LN03 입장, LN15 메이트 필터 |
| GR | 그룹 생성 | GR02 생성 기본값 |
| GJ | 그룹 가입·초대 | GJ02 내부 초대 |
| GS | 그룹 세션 | GS01 입장, GS02 세션 퇴장 |
| GL | 그룹 탈퇴·이양 | GL02 방장 탈퇴 |
| GM | 그룹 관리 | GM02 집중체크, GM07 목표 달성률 |
| GH | 그룹 홈 UI(몰입배지 등) | GH01 몰입/휴식 배지 |
| GP | 그룹 방 UI | GP01 인원 카운트 |
| GX | 나가기 경고 | GX01 타이머 중 이탈 |
| MC | 멤버카드 | MC06 하단 시간 |
| GT | 그룹 공통 타이머 | GT01 2명 제한 |
| PK | 콕 찌르기 | PK01 버튼 활성화 |
| CH | 응원 | CH01 리셋 조건 |
| IV | 초대 | IV01 외부 링크 |
| MT | 메이트 검색 | MT01 목록, MT02 검색 |
| OB | 온보딩 | OB01 분기, OB02 할일 연동 |
| CR | 캐릭터 보상 | CR01 성장 기준 |
| TD | 할 일 | TD01~TD31 |
| RP | 집중 리포트 | RP01~RP34 |
| MY | 마이페이지 | MY01~MY38 |

## 크로스 참조 예시
- AU05: 할일·리포트·마이페이지 "로그인 필요" + middleware 비로그인 차단
- SD01: 사이드바 캐릭터 = 마이페이지 대표 캐릭터
- GH01~GH03: 홈 그룹카드 = 그룹방 홈 UI 정의
- LN15: 홈 메이트 그룹 필터 = 라운지 메이트 필터 정의
- PK01: 홈·마이페이지 콕 찌르기

## ID 없음(의도적)
- 서비스 해지 / 사용자 데이터 규정 (미작성)
- 그룹방 채팅 (삭제 기능)
- 집중리포트 카테고리 리스트 스크롤 (레이아웃)

## 산출물
- `모각작_서비스정책_단순ID_gid0_붙여넣기.csv` → gid=0 정책ID 컬럼 교체용
- `모각작_정책ID_단순매핑.csv` → 구ID→신ID 대조표
- `모각작_정책변경안_AS-IS_TO-BE.csv` → 관련정책ID 갱신됨
