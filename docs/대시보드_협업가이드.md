# 모각작 대시보드 — UI · 협업 가이드

## 1. 분류 체계 (Taxonomy)

모든 지표는 두 축으로 태깅됩니다 (`metrics_catalog.json` v2).

| 축 | 값 | 질문 |
|----|-----|------|
| **Lens (관점)** | `growth` / `ux` / `tech` | 성장인가, UX 퍼널인가, 개발·계측인가? |
| **Journey (여정)** | `onboarding` → `core` → `social` → `system` | 제품 흐름 어디에 있는가? |

- **퀵 필터**: 성장 / 퍼널·UX / 개발
- **드롭다운**: 온보딩 / 핵심기능 / 소셜 / 시스템  
- 기존 CSV 대분류(`타이머`, `초대` 등)는 메타로 유지되며, Journey로 묶여 노출됩니다.

재생성: `python dashboard/build_catalog.py`

## 2. 사이드바 IA

```
모각작 데이터
├─ 공통 대시보드          ← 팀이 같이 보는 “공식” 이야기 (코드 고정)
│   ├ 홈 · 성장          Growth KPI + 전일 대비
│   ├ 여정 · UX          퍼널 4단계
│   ├ DB · 핵심          몰입·그룹·초대
│   └ GA · Tech          유입·계측 이벤트
│
└─ 내 분석 뷰            ← 개인 가설·실험 (JSON 공유)
    ├ 보드 편집          Lens × Journey 조립
    ├ (저장된 보드 목록)
    └ + 새 보드
```

**원칙:** 공통은 회의 기준, 개인은 실험. 검증되면 공통으로 승격.

## 3. 공통 vs 개인 — 추천 아키텍처

```
┌─────────────────────────────────────────────────┐
│  Common Views (코드)                            │
│  home / funnel / db / ga                        │
│  · PM·개발 합의 KPI만                            │
│  · Git으로 버전 관리                             │
└─────────────────────────────────────────────────┘
                      ▲ 승격 (검증 후)
┌─────────────────────────────────────────────────┐
│  Personal Boards (설정 + JSON)                 │
│  · localStorage: 이 PC에서만                     │
│  · export JSON: 슬랙/노션 공유                   │
│  · schema_version: 2                            │
│    { kind, title, ids, lens, journey, ... }     │
└─────────────────────────────────────────────────┘
```

| 방식 | 평가 | 결론 |
|------|------|------|
| 대시보드 전체를 사람마다 복제 | 공식 KPI 제각각 | ❌ |
| **공통(코드) + 개인(JSON)** | 기준 통일, 실험 자유 | ✅ **추천** |
| `data/boards/*.json` Git 아카이브 | 팀 공용 실험 이력 | 다음 단계 |
| GitHub Pages + URL 딥링크 | 진짜 링크 공유 | 다음 단계 |

### 운영

1. **스탠드업/주간** → 공통 홈·여정
2. **실험** → 보드 조립 → JSON 공유
3. **검증** → PM이 공통 뷰 승격 요청

### JSON 스키마 (v2)

```json
{
  "kind": "personal_board",
  "schema_version": 2,
  "title": "초대 퍼널 실험",
  "ids": ["INV_CREATE", "INV_ACCEPT", "UG_SESSION_ENTER"],
  "lens": "growth",
  "journey": "social",
  "exported_at": "2026-07-13T00:00:00.000Z",
  "note": "모각작 개인 분석 뷰 · Lens×Journey · 대시보드에서 불러오기"
}
```
