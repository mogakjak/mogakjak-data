            1. 공통은 현황·전환·데이터·이벤트 (팀 공식)

            3. 공유는 내보내기 JSON → 슬랙·노션
            4. localStorage는 PC마다 다름 → 파일로 공유
            5. 검증되면 PM이 공통 KPI로 승격
